# Рыцарские турниры

[Играть](https://baldcactus23.github.io/knight-tournament/) · [Школа копья](https://baldcactus23.github.io/knight-tournament/?mode=practice)

На телефоне поверните экран горизонтально. Ведите правую рукоятку, чтобы направить копьё. Маленькое кольцо показывает положение острия на линии соперника. Левым джойстиком наклоняйте корпус. Удар происходит при контакте. На компьютере используйте мышь для правого джойстика и WASD для наклона. После заезда можно посмотреть боковой повтор.
